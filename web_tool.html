用法：在本目录运行 python -m http.server 8000，浏览器打开 http://localhost:8000/web_tool.html。 WebBLE 需要 localhost 或 https 安全环境，不能直接双击 file:// 打开。 一次连接即可使用全部功能（刷固件、传图、校时、切页共用同一条 BLE 链路）。

① 固件刷写（BLE OTA）

选择要刷入的固件 .bin（必须是 Telink 固件，头部含 TLNK 标识）：




刷写过程中不要断开连接、不要关页面。设备只在你完成上传并「提交」之后才会真正切换固件； 上传中断的话直接重来即可，设备仍跑旧固件，不会变砖。

刷完固件后点「连接」报 NetworkError 多半不是固件坏了：设备刚重启，等几秒再连， 或按 F5 刷新本页清掉旧的 GATT 句柄（v15.7 起广播间隔已恢复 1 秒，不用再等 10 秒）。

② 图片上传


预览 = 屏幕上最终显示的样子（已含固件列翻转）。下方黑色块 = 该区域为黑。

阈值往右拖 → 更多区域变黑；往左拖 → 更多区域变白。浅色图片建议适当调高阈值。

上传完成后图片会立即显示一次并保存；要常驻显示请用下方「切到图片页」。

③ 校时与切页

刷完固件后设备时间归零，必须校时一次。时区固定按 UTC+8 发送。
